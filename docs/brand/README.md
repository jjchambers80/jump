# Eventimus brand assets

Source artwork for the Eventimus (Jump) platform brand. Eventimus is independent and not affiliated with Etix.

| File | What |
|------|------|
| `eventimus-artwork.ai` | Master Illustrator file (PDF-compatible, 1 artboard). Edit here, then export. |

The shipped logo is inline SVG in `frontend/src/components/EventimusLogo.tsx` (face symbol + wordmark, lime `#c8ff00` in dark mode). Update that component when the artwork changes; this folder is not served to the app.
